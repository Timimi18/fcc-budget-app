# Object-Oriented Budget App (freeCodeCamp Project)

A clean Python application that models personal finances using robust Object-Oriented Programming (OOP) architectures. The application allows users to spin up tracking categories (e.g., Food, Clothing, Entertainment) with an embedded accounting ledger capable of handling structural deposits, defensive withdrawals, multi-account ledger transfers, and real-time ledger auditing.

This project was built to satisfy 100% of the rigorous formatting specs for the **freeCodeCamp Python Certification** curriculum.

## 📊 Project Objectives & Core Features
1. **Ledger Management Class:** Every budget category maintains an explicit instance ledger list mapping sequential numeric transactions and description objects.
2. **Dynamic Ledger Auditing (`check_funds`):** Implements automated verification layers to protect ledger sub-accounts from accidental over-drafting or invalid transfer sequences.
3. **Custom Object Representation (`__str__`):** Overrides standard string output protocols to compile financial records into centered, column-aligned receipts.
4. **ASCII Visualization Engine:** An independent algorithm that structures a cleanly scaled vertical bar graph visualizing exact category expenditure ratios.

## 🛠️ Core Technical Concepts Demonstrated
* **Encapsulation & OOP:** Building stateful domain models with tailored instance methods and semantic operator overrides.
* **String Processing:** Mastery over explicit alignment markers (`<`, `>`), variable truncation boundaries, and structured whitespace compilation rules.
* **Data Aggregation:** Parsed internal dictionary elements containing multi-tiered absolute value logic to compute exact data trends without mutating reference values.
